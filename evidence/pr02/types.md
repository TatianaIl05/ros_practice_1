# PR02. Типы и поля сообщений

## Основные топики

### `/turtle1/pose`

- **Тип:** `turtlesim/msg/Pose` (Jazzy). Для Lyrical - `turtlesim_msgs/msg/Pose`.
- **Назначение:** положение черепахи в поле turtlesim.
- **Поля:**
  - `x` - координата X,
  - `y` - координата Y,
  - `theta` - угол поворота,
  - `linear_velocity` - линейная скорость,
  - `angular_velocity` - угловая скорость.

Поза публикуется постоянно, даже когда черепаха стоит (скорости равны 0).

### `/turtle1/cmd_vel`

- **Тип:** `geometry_msgs/msg/Twist`.
- **Назначение:** команда движения для черепахи.
- **Поля:**
  - `linear` - вектор линейной скорости (`x`, `y`, `z`),
  - `angular` - вектор угловой скорости (`x`, `y`, `z`).

Для turtlesim используются:
- `linear.x` - движение вперёд/назад,
- `angular.z` - поворот вокруг вертикальной оси.
